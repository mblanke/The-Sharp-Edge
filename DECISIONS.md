- **2026-07-23 — Reference Docs/ kept in repo** as historical source material (v1 single-file prototype, master file original, print PDF, logo source). The zip is gitignored.
- **2026-07-23 — Phase 3 RAG delegated to the Atlas stack** (user direction). No in-app chunker/embedder/watcher, no book/chunk tables. Corpus = `\\Olympus_NAS\Media\References\Cooking`, auto-ingested by Atlas `rag-ingest.timer` into Qdrant `references_v2`; retrieval via rag-api :8099 with client-side folder filter (rag-api takes only {question, top_k}); synthesis via LiteLLM `cluster` alias (GB10s). Cooking shelf treated as private tier → local models only; AnthropicProvider hard-refuses corpus chunks. Possible later improvement on Atlas: server-side source_folder filter on /retrieve.
- **2026-08-24 — /export/master.md requires auth.** All recipes are owner-authored/public tier, but the file enumerates the whole notebook in one request; bearer token keeps it write-tier like the other bulk operations. Content is emitted in a format the seed importer's parsers re-parse losslessly (round-trip tested); manifest-owned metadata (slugs, yields) travels as prose the parser ignores. Timers are app-only and not exported.
- **2026-08-24 — Tag/RecipeTag and NotebookPage kept and implemented** (they were dead schema since 0001). Tags feed home filtering and future "what can I make" search; notebook pages are load-bearing for the cards.pdf glue-in index (§10). Both live on `recipe`, not `recipe_version` — page/tag churn shouldn't mint versions.
- **2026-08-24 — Plan endpoints beyond §6:** `PATCH /plan/shopping-list/{id}` (check toggle) and `DELETE /plan/{id}` (remove a slot) — the spec lists only GET/POST but a usable list needs both; auth like all writes. Weeks normalize to their Monday server-side. Regenerating a list discards checkmarks (boring option — the list is derived state).
- **2026-08-24 — Book scope is a client-side filter with a deeper over-fetch** (48+ instead of 24) because rag-api still takes only {question, top_k}. When Atlas grows a server-side `source_folder`/`source_path_prefix` filter, drop `_in_books` and the boosted fetch in `services/atlas_rag.py`. `/search?kind=` stays unimplemented until Atlas returns chunk `kind` metadata.
- **2026-08-24 — cook_session table (migration 0004), beyond §5.** App-only history ("last cooked · what we changed"); never included in master.md or cards.pdf exports (no editorializing rule).
- **2026-08-24 — POST /recipes/parse-photo (Anthropic vision), beyond §6.** Photos of the owner's own notebook are owner-authored → public tier; the request carries only the image plus a fixed instruction, guarded by the same `ensure_public_tier` firewall the AnthropicProvider uses (unit-tested).
